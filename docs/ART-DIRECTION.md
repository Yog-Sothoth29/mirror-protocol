# 镜面协议 · 视觉来源与重建简报

以下为根据已完成作品整理的可复用制作简报，不冒充图片工具历史调用的逐字提示词。PNG为生成原稿，WebP为同一原稿的加载版本；没有用压缩重新绘画人物。

蓝白图：宽屏日系插画；蓝白全息空间，蓝色长发和蓝瞳、白蓝女仆装、鲸形饰物；人物集中右侧，左侧保留安静的文字与输入空间，轻薄玻璃、水面折射、冷色细线。

长征图：宽屏黑色赛博空间；白发红瞳、星形发饰、红白水手服，右侧人物，左侧暗场；暗红电路、碎镜、低频红色信号。根据用户追加要求，将背景改为黑色，并再次编辑logo后环为正面正圆，禁止透视压扁成椭圆。

几何图标：蓝鲸圆环与红色星形同人符号分开绘制为SVG；红色符号的外环使用圆心50/50、半径47的圆，图标按等比例contain显示。标志为同人风格再设计，不标作TFR官方logo。切换徽章是独立正圆裂镜符号，不直接裁切人物图。

交互美术：蓝白为主状态，黑红为偶发入侵；裂镜只改变背景绘制，不移动消息、输入或控件。红色图标是5.6秒缓慢光晕，没有高频闪烁；减少动态效果时取消装饰动画。主视觉右下的额外装饰卡已移除，避免挡住人物。

研究来源、作者和链接见README「来源」；用户提供的两张破镜/人物参考及已下载的Acca《lavender-snow》用于私人设计参考。原始同人图片没有作为自有插画打包发布。本交付没有发布到社区。

## v2.1 HUD 与动效

HUD 的视觉语法来自三处：终端/机柜的长征机国策图标、MIT 的 `dsh-theme-longmarch` 数据雨与 CRT 分层、以及本主题已有的镜面/圆环。`assets/longmarch-sigil.svg` 为另绘：外圈虚线环、中央机柜屏幕、红星、CPUPF / LONG MARCH 字样；它只作为 6% 透明度水印，不替代人物原画或官方徽记。

- 蓝色状态：左侧网格、右侧同心环、冷色浮尘、瞄具与细刻度；保持明亮阅读区。
- 红色状态：右侧二进制雨、余烬、雷达扇、BREACH 条与红色四角框；数据雨只落在人物侧，不压正文。
- 所有 HUD 位于正文之下、`pointer-events:none`；不是可交互节点，也不改变原生布局。
- 动效规则与实测见 `MOTION-PERFORMANCE.md`；未把第三方代码、截图或模组美术打进主题包。
